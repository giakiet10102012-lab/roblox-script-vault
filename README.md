# ⚡ Roblox Script Vault & Account Manager

Ứng dụng web toàn diện giúp lưu trữ, tìm kiếm tức thì, phân loại toàn bộ Script Roblox (Blox Fruits, Dead Rails, Fisch, Kaitun, v.v.), tích hợp bộ tạo tài khoản Roblox ngẫu nhiên và quản lý tài khoản (Account Vault) bảo mật, tiện lợi.

---

## 🌟 Tính Năng Chính

### 1. 📜 Kho Script Roblox Đa Năng
- **40+ Scripts có sẵn**: Được tích hợp sẵn toàn bộ scripts từ Blox Fruits (Kaitun, Lấy tộc Cyborg/Ghoul, Farm rương, Nhặt trái, Fix lag...), Dead Rails, Fisch, Arise, Pls Donate, Grow a Garden, 99 Nights in the Forest, Dev Tools (Dex Explorer, SimpleSpy).
- **Bộ lọc thông minh**: Lọc nhanh theo Game hoặc Thẻ tính năng (#Kaitun, #Auto Farm, #Fix Lag, #PvP / Aim, #Fruit / Chest, #Hop Server, #Có Key, #Không Key).
- **Tìm kiếm tức thì (Ctrl+K)**: Tìm theo tên script, nội dung code, ghi chú hoặc tên game.
- **Sao chép 1-Click**: Bấm sao chép kèm thông báo trực quan, nút xem toàn bộ code Lua, nút truy cập link Get Key nhanh.
- **Thêm / Sửa / Xóa Script**: Giao diện modal trực quan để thêm các script mới của bạn bất kỳ lúc nào.

### 2. 🔑 Trình Tạo Nick & Mật Khẩu Roblox
- **Tạo Username Roblox ngẫu nhiên**: Ghép từ chữ cái và số không có nghĩa (VD: `k8x9m2a4`, `ab34kx91`, `vx7q9pl1`), đảm bảo 100% tuân thủ quy định Roblox (3-20 ký tự, hợp lệ).
- **Tạo Mật khẩu ngẫu nhiên**: Mặc định tạo mật khẩu chuẩn 8 ký tự (chữ + số, dễ dùng, an toàn).
- **Tạo Cặp Nhanh (user:pass)**: Tạo và sao chép nhanh combo để đăng ký hoặc nạp vào phần mềm auto.
- **Lưu Trực Tiếp**: 1 nút bấm để lưu ngay cặp tài khoản vừa tạo vào Quản Lý Tài Khoản.
- **Tạo Hàng Loạt (Batch)**: Sinh 5, 10, 20 tài khoản cùng lúc và sao chép toàn bộ danh sách chỉ bằng 1 cú click.

### 3. 👤 Quản Lý Tài Khoản (Account Vault)
- **Mật khẩu luôn hiển thị**: Mật khẩu hiển thị trực tiếp bằng văn bản rõ ràng, không che dấu `***`.
- **Copy Siêu Tốc**: Bấm vào Username, Mật khẩu hoặc nút "Copy combo (user:pass)" để sao chép tức thì.
- **Phân loại & Trạng thái**: Quản lý tài khoản theo Game, mục đích sử dụng (Nick farm, nick bán gem, acc clone...), và trạng thái (Sẵn sàng, Đang treo, Đã bán, Khóa).
- **Thêm / Sửa / Xóa**: Dễ dàng chỉnh sửa ghi chú, cập nhật level, trái ác quỷ hoặc xóa tài khoản cũ.

### 4. ☁️ Cloud & Tiện Ích Treo Game
- Lưu trữ danh bạ link Cloud VPS miễn phí (LT4C), Cloud Phone (MaxCloudPhone), GPU VM (EzyCloudX).
- Link tải các Executor / Client chạy được Banana Hub (Volcano, Swift).
- Ghi chú tuyển chân săn Leviathan Hydra.

### 5. 💾 Sao Lưu & Khôi Phục Dữ Liệu
- **LocalStorage**: Mọi dữ liệu tự động lưu trong trình duyệt của bạn.
- **Xuất Backup JSON**: Tải toàn bộ kho script và tài khoản về máy tính.
- **Nhập Backup JSON**: Khôi phục hoặc chuyển dữ liệu sang máy khác chỉ trong 1 giây.
- **Xuất file user:pass (.txt)**: Xuất danh sách tài khoản dạng text combo để nạp vào tool auto/treo game.

## 🚀 Cách Sử Dụng

### Cách 1: Mở trực tiếp trên máy tính
1. Mở thư mục `roblox-script-vault`.
2. Nhấp đúp vào file `index.html` để mở trong trình duyệt (Chrome, Edge, Cốc Cốc, Brave, Firefox, v.v.).

### Cách 2: Đẩy lên GitHub & Mở Web Online 24/7 (GitHub Pages)
1. Mở PowerShell trong thư mục này.
2. Chạy lệnh:
```powershell
.\deploy-github.ps1
```
3. Nhập **GitHub Token (PAT)** khi được hỏi.
4. Script sẽ tự động tạo repository trên tài khoản GitHub của bạn, tải lên toàn bộ code và kích hoạt GitHub Pages để bạn có link web online chạy trên cả điện thoại và máy tính!
